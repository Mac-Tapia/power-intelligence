# API, mensajes y datos contractuales

- `schemas/json/`: datos y manifiestos validados; versionar y probar por consumidor.
- `openapi/`: límites HTTP, autenticación y contratos de comandos (por implementar).
- `events/`: eventos con causación/correlación y compatibilidad por versión.
- `protobuf/`: solo si se justifica por interoperabilidad/rendimiento medido.
- `units/`: convenciones explícitas kV, kW, kvar, kVA, p.u., A, ohm, CRS; no asumir unidades implícitas.
