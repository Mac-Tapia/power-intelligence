# ADR-0003: GIS, topología eléctrica y unifilar son modelos separados

- **Estado:** Aceptada.
- **Decisión:** importar GIS como dato fuente, construir conectividad a nivel terminal/fase/switch y generar layout unifilar como proyección editable. Ninguna proximidad GIS establece conectividad de forma automática.
- **Consecuencias:** identidades persistentes por activo, trazabilidad de cada transformación y pruebas de equivalencia de conectividad.
