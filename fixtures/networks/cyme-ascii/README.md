# Exportación CYME ASCII sintética

Formato de exportación ASCII de CYMDIST para probar el lector offline (spec 001, T010). Los valores son sintéticos y no corresponden a ninguna red real. `NET_OK` es un alimentador válido con conexión ideal `DEFAULT` y un interruptor abierto. `NET_BAD` reúne los rechazos: código fuera del catálogo, sección monofásica, `DEFAULT` de 30 m y tipo de carga no soportado.
